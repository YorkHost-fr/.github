# 🌐 YorkHost — Infrastructure. Performance. Innovation.

**YorkHost** est un hébergeur français spécialisé dans les infrastructures haute performance pour **jeux, serveurs dédiés, colocation, et services cloud**.
Nous concevons, opérons et innovons sur l’ensemble de notre stack : matériel, réseau, et logiciel.

---

## 🏗️ Nos domaines d’expertise

* 🖥️ **Game Hosting** — serveurs haute fréquence optimisés (FiveM, Minecraft, ARK, Palworld, etc.)
* 🧩 **Infrastructure Cloud** — VPS NVMe, serveurs dédiés Ryzen & Xeon, virtualisation KVM et Proxmox
* 🛰️ **Networking** — tunnels BGP/GRE/VXLAN, DDoS mitigation, redondance StormWall & Cloudflare
* 🧠 **Logiciels internes** — développement de panels (Athena, Connextix), API HostBill, monitoring et automatisation complète

## 🧩 Stack technique

* **Backend :** Node.js (Express), PHP (HostBill API)
* **Frontend :** Next.js / React / TailwindCSS
* **Infra :** Proxmox, Kubernetes, Docker, GitHub Actions, PM2
* **Monitoring :** Zabbix, Grafana, Telegram/Discord Alerts
* **Base de données :** Postgress, Redis
